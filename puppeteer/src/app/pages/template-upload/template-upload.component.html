Archivos HTML

Este es el HTML que se usará como cuerpo principal del PDF.
Si lo proporcionas, se usará como cabecera del PDF.
Si lo proporcionas, se usará como pie del PDF.
  • Variables dinámicas: escribe las variables con el formato {{'{{NOMBRE_VARIABLE}}'}}. Ejemplos: {{'{{NOMBRE}}'}}, {{'{{FECHA}}'}}, {{'{{IMPORTE_TOTAL}}'}}.
  • Formato de las variables: usa nombres en MAYÚSCULAS, sin espacios y con guiones bajos si lo necesitas: {{'{{NOMBRE_COMPANIA}}'}}, {{'{{CODIGO_DOCUMENTO}}'}}.
  • Header y footer repetidos: el HTML de cabecera y pie se aplicará en todas las páginas del PDF. Puedes usar en ellos las mismas variables dinámicas (por ejemplo {{'{{NOMBRE_COMPANIA}}'}}, {{'{{CODIGO_DOCUMENTO}}'}}, etc.).
  • Números de página: para mostrar el número de página actual y el total de páginas, incluye en el footer este patrón: Página <span class="pageNumber"></span> de <span class="totalPages"></span> Ejemplo completo: ssssss qqqqqq · Página <span class="pageNumber"></span> de <span class="totalPages"></span>
  • Estructura recomendada:
    • El HTML principal puede ser un documento completo (<html>, <head>, <body>).
    • El header y el footer es recomendable que sean solo el bloque de contenido (por ejemplo un <div>...</div>), sin envolver en <html> ni <body>.
  • Estilos: puedes usar CSS en <style> o estilos en línea. Evita márgenes externos muy grandes en header/footer; el generador de PDF ya aplica sus propios márgenes de página.
